# MeritCoin — Backend (NestJS)

API REST em `/api/v1` · Prisma + PostgreSQL · Swagger em `/docs`.

```bash
cp .env.example .env
npm install
npx prisma migrate dev
npx prisma db seed
npm run start:dev
```
